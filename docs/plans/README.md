# Execution Plans

Use one canonical lifecycle:

- `active/YYYY-MM-DD-<slug>.md` for approved or in-progress work.
- `completed/YYYY-MM-DD-<slug>.md` after the outcome, verification, and follow-ups are recorded.

Keep the opening-date filename when moving a plan. Each active plan must identify root and
submodule ownership, external contracts, financial/data safety gates, rollback, and acceptance
criteria.

Existing plans outside this directory are legacy inputs until reviewed. Do not bulk-label them
complete or treat old checkboxes as current operational truth.
